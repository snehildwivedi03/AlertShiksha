**...AlertShiksha....**  
**Disaster Preparedness & Response Education System**

AlertShiksha is an interactive educational platform designed to teach students in schools and colleges about disaster preparedness and emergency response.

-> 🔍 Key Features

- 📘 Interactive learning modules for disaster awareness
- 🧠 AI-powered quizzes using **Google Gemini API**
- ♿ Focus on usability, accessibility, and real-world practicality

## 🚀 Goals

To empower students with the knowledge and tools needed to respond effectively during emergencies through engaging and accessible education.
